# 超星学习通 · 名著阅读刷时长助手

一个运行在浏览器 Tampermonkey（油猴）中的用户脚本，用于辅助完成超星学习通网页版《名著阅读》的阅读与视频时长任务。

脚本只做**页面自动化**：自动滚动、翻页、播放、切换下一个任务点。它不修改平台数据，也不绕过平台的完成条件、任务点或风控校验。

> 当前版本：**v0.5.0**  
> 适用页面：超星学习通网页版《名著阅读》阅读页、视频播放页  
> 浏览器：Chrome、Edge 等 Chromium 内核浏览器（需安装 Tampermonkey）

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 刷书 | 自动滚动正文，到达页底后等待并点击「下一页 / 下一章」 |
| 翻页识别 | 支持文字带图标、常见类名、`aria-label`、`title`，可手动校准 |
| 刷新恢复 | 卡住时自动刷新，保存阅读进度并继续 |
| iframe 正文 | 正文位于子框架时仍可自动滚动、翻页 |
| 刷视频 | 自动播放、静音，播放期间不滚动、不切页 |
| 完整播放 | 视频自然结束后停留 3 秒复核，只切换一次 |
| 任务点 | 无「下一集」按钮时，滚动到下一个「任务点」并接管其中的视频 |
| 弹窗处理 | 自动点击「任务点未完成」弹窗内的「下一节」 |
| 倍速 | 仅保留 `1× / 1.5× / 2×` |
| 后台保持 | Web Worker 定时器 + 页面可见性伪装，降低后台节流影响 |
| 自动恢复 | 刷新或重新打开页面后，可自动继续未完成任务 |

## 安装前准备

1. 使用 **Chrome 或 Edge** 浏览器（其他 Chromium 浏览器也可，但未逐一测试）。
2. 能正常登录超星学习通网页版，并进入《名著阅读》课程。
3. 仅支持电脑网页版；手机 App、小程序或移动端网页不在适配范围内。
4. 确认浏览器允许安装扩展。公司/学校电脑如果禁用了扩展安装，需要先联系管理员。

> Edge 与 Chrome 使用相同的 Chromium 内核，脚本本身不存在“只适配 Chrome”的问题；如果 Edge 不生效，通常是扩展权限或脚本未启用，而不是内核差异。

## 安装 Tampermonkey

### Chrome

1. 打开 Chrome 应用商店，搜索 **Tampermonkey**。
2. 进入扩展详情页，点击「添加至 Chrome」→「添加扩展程序」。
3. 安装完成后，点击浏览器右上角的拼图图标，把 Tampermonkey 固定到工具栏。

> 如果 Chrome 应用商店无法访问，可以改用 Edge 加载项商店安装 Tampermonkey，再回到 Chrome 使用，或直接在 Edge 中按下方步骤安装。

### Edge

1. 打开 Edge 加载项商店，搜索 **Tampermonkey**。
2. 点击「获取」→「添加扩展」。
3. 如果使用 Chrome 应用商店安装，需要先在 `edge://extensions` 打开「允许来自其他应用商店的扩展」。
4. 安装后把 Tampermonkey 图标固定到工具栏。

## 给扩展插件权限

Tampermonkey 需要能够读取和修改超星页面，脚本才能运行。安装后请检查以下权限。

### Chrome

1. 地址栏输入 `chrome://extensions` 并回车。
2. 找到 **Tampermonkey**，点击「详细信息」。
3. 找到「网站访问权限」/「Site access」，选择：
   - **在所有网站上**（最简单）；或
   - **在特定网站上**，至少加入以下域名：
     - `chaoxing.com`
     - `chaoxing.cn`
     - `chaoxing.com.cn`
     - `xuexitong.com`
4. 如果扩展详情页出现「允许用户脚本 / Allow User Scripts」开关，请一并打开。
5. 如果只是本地打开 HTML 测试，才需要打开「允许访问文件网址」；正常刷超星不需要。

### Edge

1. 地址栏输入 `edge://extensions` 并回车。
2. 找到 **Tampermonkey**，点击「详细信息」。
3. 在「网站访问权限」中选择「在所有网站上」，或把上面的超星域名加入允许列表。
4. 如果扩展详情页出现「允许用户脚本 / Allow User Scripts」开关，请一并打开。
5. 如需在 InPrivate 窗口使用，可打开「在 InPrivate 中允许」，但更建议使用普通窗口。

### 检查 Tampermonkey 是否启用

- 点击工具栏的 Tampermonkey 图标，确认顶部显示「已启用」。
- 如果图标是灰色，点击开关启用。
- 打开任意超星页面，Tampermonkey 图标上应出现数字角标（表示有脚本在该页运行）。

## 安装脚本

脚本文件：`chaoxing-reading-helper.user.js`

### 方式一：从文件导入（推荐）

1. 点击 Tampermonkey 图标 →「管理面板 / Dashboard」。
2. 打开「实用工具 / Utilities」标签。
3. 在「从文件导入」区域选择 `chaoxing-reading-helper.user.js`。
4. 浏览器会打开脚本安装页，核对名称和版本后点击「安装 / Install」。

### 方式二：新建脚本并粘贴

1. Tampermonkey 管理面板 →「添加新脚本 / Create a new script」。
2. 删除编辑器里自带的模板内容。
3. 用文本编辑器打开 `chaoxing-reading-helper.user.js`，全选复制。
4. 粘贴到 Tampermonkey 编辑器，按 `Ctrl + S` 保存。
5. 确认脚本列表里出现「超星学习通 · 名著阅读刷时长助手」，并且开关为启用。

### 方式三：拖入浏览器

把 `.user.js` 文件直接拖进已打开 Tampermonkey 的浏览器窗口，通常会弹出安装页；如果没有反应，改用方式一。

### 安装后检查

1. 打开超星学习通《名著阅读》页面。
2. 页面右上角应出现深色控制面板，标题为「名著阅读助手」，版本显示 `v0.5.0`。
3. 如果没有面板：
   - 刷新页面；
   - 检查 Tampermonkey 是否启用；
   - 检查脚本是否启用；
   - 检查网站访问权限是否包含当前域名；
   - 检查地址是否为 `chaoxing.com` / `chaoxing.cn` / `xuexitong.com` 域名。

## 使用说明

### 刷书模式

> **重要：先点进具体章节的正文阅读页，再启动刷书。**  
> 不要停在课程目录、章节目录或作业列表页，否则脚本找不到正文和「下一页」。

1. 登录超星学习通，进入《名著阅读》课程。
2. 点击某个章节，进入能看到正文的阅读页。
3. 页面右上角出现控制面板后，选择「刷书」。
4. 按需调整：
   - **阅读速度**：慢 / 中 / 快 / 自定义；
   - **滚动步长**：每次向下滚动的像素；
   - **滚动间隔**：两次滚动之间等待的毫秒数；
   - **翻页等待**：到达页底后等待多久再翻页（随机浮动）。
5. 点击「开始刷时长」。
6. 脚本会自动滚动；到达页底后等待并点击「下一页 / 下一章」。
7. 需要暂停时点击「停止刷时长」。

说明：

- 如果自动翻页找不到按钮，先使用「翻页校准」（见下文）。
- 如果页面卡住，开启「卡住时自动刷新并恢复进度」后，脚本会保存进度并刷新继续。
- 脚本会检测「阅读完成 / 已读完 / 恭喜完成」等提示，检测到后自动停止。
- 正文位于 iframe 中时，脚本会尝试让顶层页面控制，或由子框架内的脚本实例继续刷书。

### 刷视频模式

1. 进入具体视频播放页（有播放器、任务点、播放按钮的页面），不要停在课程目录。
2. 在面板顶部选择「刷视频」。
3. 选择播放倍速：`1×`、`1.5×`、`2×`。
4. 建议保持「静音播放」「播完自动切换下一集」「防暂停 / 掉线自动恢复」开启。
5. 点击「开始刷时长」。
6. 脚本会自动播放当前视频；**播放期间不会滚动、不会切页、不会重复点击**。
7. 视频自然结束后：
   - 先停留 3 秒复核，确认真的播完；
   - 如果出现「当前章节还有任务点未完成，是否去完成？」弹窗，脚本只点击弹窗内的「下一节」；
   - 然后切换到下一个视频/任务点。
8. 如果切换后 30 秒仍没有新视频，脚本会停止，避免无限操作。

建议：

- 首次使用先用 `1×` 或 `1.5×`，确认页面和任务点正常后再尝试 `2×`。
- 平台要求「观看时长 ≥ 总时长的 90%」时，倍速过高可能导致观看时长不足或触发人机验证。
- 视频播放期间尽量不要手动滚动页面、点击下一集或切换标签页。

### 面板与快捷键

- **拖动**：按住面板顶部标题栏拖动位置。
- **最小化**：点击标题栏的「—」，收起为右下角悬浮球；点击悬浮球恢复。
- **隐藏**：点击「×」隐藏面板。
- **显示/隐藏快捷键**：`Alt + Shift + C`。
- **开始/停止**：面板主按钮；也可以在 Tampermonkey 菜单里选择「开始 / 停止刷时长」。
- **设置保存**：模式、速度、倍速、复选框等会自动保存，下次打开沿用。
- **自动恢复**：开启「刷新或重开后自动继续」后，刷新页面会尝试恢复上次未完成的任务。

### 翻页校准

如果刷书能滚动，但到页底不翻页，通常是「下一页」按钮的文字或结构比较特殊。

1. 在「刷书」标签页找到「翻页按钮定位」。
2. 点击「校准「下一页」」。
3. 鼠标移到页面底部真正的「下一页」按钮上，点击一次。
4. 面板日志出现「已记录翻页按钮定位」即成功。
5. 重新点击「开始刷时长」。

校准选择器会按当前网站域名保存。如果页面改版，点「清除校准」后重新校准。

## 常见问题

### 1. 页面右上角没有面板

按顺序检查：

1. Tampermonkey 是否启用；
2. 脚本是否在 Tampermonkey 脚本列表中启用；
3. 扩展是否有当前网站的访问权限；
4. 当前地址是否是 `chaoxing.com` / `chaoxing.cn` / `xuexitong.com` 域名；
5. 安装或修改脚本后是否刷新了页面；
6. 是否被其他同类脚本/广告拦截插件干扰，可暂时关闭其他脚本再试。

### 2. 刷书不滚动 / 不翻页

- 确认已经进入**正文阅读页**，不是目录页。
- 尝试「翻页校准」。
- 关闭「自定义」速度，先用「中」速测试。
- 打开「高级 → 显示运行日志」，查看是否有「找不到翻页按钮」「正文容器未找到」等提示。
- 如果正文是 Canvas、图片或加密渲染，脚本无法读取文字和按钮，这种情况不支持。

### 3. 刷视频反复切换 / 页面上下滑动

- 确认使用的是 **v0.5.0**。
- 只保留一个超星标签页运行脚本，不要同时开多个视频页。
- 视频播放期间不要手动滚动或点击下一集。
- 打开日志，确认是否出现多个实例同时接管；如有异常，刷新页面后重新启动。
- 如果仍然复现，记录面板状态、日志和页面地址，提交 Issue。

### 4. 出现人机验证 / 滑块验证

- 立即点击「停止刷时长」。
- 手动完成验证后，再决定是否继续。
- 建议改用 `1×`，并保持页面在前台可见。
- 脚本不会自动破解验证码，也不建议尝试绕过。

### 5. 视频结束弹窗没有自动点「下一节」

脚本只识别弹窗内文字为「下一节」的按钮，并要求弹窗包含「任务点未完成 / 是否去完成」提示。

如果你们平台的按钮文案不同，或者弹窗在跨域 iframe 中，可能无法识别。请把弹窗的 HTML 片段（至少包含按钮文字和父级结构）发给作者适配。

### 6. Edge 能用吗？

可以。Edge 与 Chrome 同为 Chromium 内核，脚本没有针对 Chrome 的专属 API。Edge 不生效通常是扩展权限、脚本未启用或安装方式的问题。

### 7. 可以最小化 / 切到后台吗？

可以最小化面板或切换标签页，脚本使用 Web Worker 降低后台定时器节流，并伪装页面可见性。但平台仍可能检测焦点、可见性或播放状态，**不能保证后台一定安全**；如果平台明确要求“观看时不可离开”，建议保持页面可见。

### 8. 「作业」模式为什么是灰色的？

「自动完成作业」目前只保留代码框架和入口，尚未实现。脚本不会自动答题或提交作业。

### 9. 设置保存在哪里？如何重置？

配置保存在 Tampermonkey 存储或站点的 `localStorage` 中，键名以 `cx_helper_` 开头。刷新页面后仍会保留。

如需重置，可在 Tampermonkey 中删除脚本后重新安装，或清除该站点的本地存储。注意：清除后阅读进度、校准选择器也会丢失。

## 注意事项与免责声明

1. **先进入正文/播放页再启动**：刷书必须点进具体章节正文，刷视频必须进入播放器页面。
2. **一次只跑一个任务**：不要同时开多个标签页刷书/刷视频，避免多个实例争抢页面。
3. **倍速越高风险越大**：平台按任务点和观看时长计算进度，`2×` 可能触发风控；稳妥起见使用 `1×`。
4. **不要手动干预**：视频播放期间不要滚动、点击下一集或频繁切换标签页。
5. **脚本不绕过平台校验**：不修改平台数据、不破解验证码、不代替提交作业。是否完成课程仍以平台判定为准。
6. **账号风险自负**：使用自动化脚本可能违反平台规则，可能导致任务无效、账号受限等后果。请自行评估并承担风险。
7. **页面改版可能导致失效**：超星页面结构更新后，翻页、弹窗、视频识别可能需要重新适配。
8. **仅供个人学习辅助**：请勿用于商业用途或大规模代刷。
